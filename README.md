# ✊🖐✌ Jokenpô (Pedra, Papel e Tesoura)

Um jogo de **Jokenpô** simples, intuitivo e moderno desenvolvido para rodar diretamente no navegador. Desafie a **Alexia** em uma partida clássica de Pedra, Papel e Tesoura e acompanhe o placar em tempo real!

## 🚀 Funcionalidades

- **Escolha Visual:** Interface simples com botões interativos (✊, 🖐, ✌) para fazer a sua jogada.
- **Placar Dinâmico:** Sistema que contabiliza a sua pontuação e a pontuação da Alexia a cada rodada.
- **Inteligência Artificial (Alexia):** Adversária virtual que faz escolhas de forma totalmente aleatória e justa.
- **Design Responsivo:** Layout limpo e adaptável para diferentes tamanhos de tela.

## 🛠 Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias web fundamentais:
- **HTML5:** Estruturação dos elementos da página.
- **CSS3:** Estilização, layout e responsividade.
- **JavaScript (ES6):** Lógica do jogo, computação de resultados e manipulação do DOM.

## 🎮 Como Jogar

1. Acesse o jogo através do link do projeto.
2. Escolha a sua jogada clicando em um dos três ícones:
   - ✊ **Pedra** (Ganha de Tesoura, perde para Papel)
   - 🖐 **Papel** (Ganha de Pedra, perde para Tesoura)
   - ✌ **Tesoura** (Ganha de Papel, perde para Pedra)
3. A Alexia fará a escolha dela simultaneamente.
4. O resultado da rodada será calculado e o placar atualizado automaticamente!

## 💻 Como Executar Localmente

Se desejar baixar e rodar o projeto na sua máquina:

1. Clone este repositório:
   ```bash
   git clone https://github.com/jordanjjfml/jokenp-.git
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd jokenp-
   ```
3. Abra o arquivo `index.html` em qualquer navegador web de sua preferência.
